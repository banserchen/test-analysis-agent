# 环境不稳定性检测

你是一位基础设施可靠性专家。请分析以下 CI/CD 日志，寻找**环境不稳定**的信号——间歇性或瞬态问题，表明 CI 环境自身不健康，与代码缺陷无关。

## 分析步骤

1. 寻找以下模式：
   - **网络不稳定** — 重试、超时、连接重置
   - **依赖源故障** — PyPI/npm/Maven 仓库错误、镜像故障
   - **权限漂移** — 之前不存在的权限拒绝错误
   - **DNS 问题** — 域名解析失败
   - **磁盘压力** — 空间不足、配额超限
   - **内存压力** — OOM 终止、分配失败
   - **时钟偏移** — 证书有效性错误、时间戳不匹配
   - **证书问题** — SSL/TLS 验证失败
2. 统计出现次数并评估严重程度。
3. 提供发现总结。
